用 Whisper 自動生成 SRT 字幕

不用裝任何軟體，全部在瀏覽器裡完成。把影片轉成 mp3 上傳，跑一段程式碼，幾分鐘後下載字幕檔。

1

打開 Colab

用 Google 帳號登入，新增一個筆記本。

colab.research.google.com 前往 →
2

（建議）先切換成 GPU

執行階段 → 變更執行階段類型 → 硬體加速器選 T4 GPU → 儲存。

45 分鐘音檔用 GPU 約 5–10 分鐘，用 CPU 可能要 40 分鐘以上。

注意：切換後頁面會重新連線，要在切換之後才上傳檔案。
3

上傳音訊檔

建議先把影片轉成 mp3 再上傳，檔案小很多、速度快很多，字幕結果完全一樣（Whisper 只聽聲音）。

左側「檔案」圖示 → 上傳檔案圖示，選好檔案後務必等左下角的轉圈圈完全停止再進行下一步。

最常出錯的原因：沒等上傳完成就直接跑下一步。
4

貼上並執行程式碼

把下面的「你的檔名.mp3」換成你實際上傳的檔名（要完全一致，含底線、空格），貼進 cell 後按左邊的播放鍵。

python · colab cell 
!pip install -U openai-whisper
!whisper "你的檔名.mp3" --model medium --language Chinese --output_format srt
參數說明： model 可選 tiny / base / small / medium / large，越大越準但越慢；medium 是中文的平衡點。檔名若含空格記得保留引號。
5

下載 SRT

跑完後左側檔案列表會多一個 .srt 檔，右鍵點它選「下載」就能存到電腦上直接套用到剪輯軟體。

常見問題自查

  • 出現「No such file or directory」→ 檔案還沒上傳完，或檔名打錯
  • 字幕只跑出前面一小段 → 上傳沒等完成，刪掉重傳一次
  • 跑很久還沒好 → 確認是不是還在用 CPU，沒切到 GPU
  • 專有名詞、人名常認錯 → 屬正常現象，跑完後人工校對一輪
